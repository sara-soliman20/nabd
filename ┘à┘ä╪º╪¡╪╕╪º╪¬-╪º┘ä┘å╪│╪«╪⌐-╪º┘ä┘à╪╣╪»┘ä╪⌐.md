# Nabd v12 – fixes and deployment status

## Code changes
- Voice mode: added guard against delayed microphone/VAD captures when Nabd is speaking or processing; with barge-in disabled, captures that started during playback are discarded.
- Browser speech recognition fallback: clears stale interim text while Nabd is speaking when barge-in is disabled.
- Fixed illustration-generation endpoint in server/index.js to call the imported `imageAI()` function instead of the undefined `imageGemini()` name.
- Added regression tests for voice capture guards.

## Deploy secrets
Keep `GEMINI_API_KEY` (and optionally `GROQ_API_KEY`) only in Render Environment settings. Never place these secrets in GitHub repository files, the frontend, or GitHub Actions Variables. The Android workflow only needs non-secret `API_BASE` and `PUBLIC_URL` variables.

## v13 – voice fixes (this pass)
- Mic button stayed disabled / fell back to browser mode when the free Render server was asleep at page load: health check now retries (every 4s, up to 10 times) and `start()` re-checks; a "server is waking up" message replaces the misleading "browser blocks recording".
- Echo-discard branch no longer resets `busy`/status while Nabd is still speaking or thinking.
- Browser TTS watchdog: Chrome on Android sometimes never fires `onend`, which froze the conversation on "speaking".
- Android APK workflow now adds RECORD_AUDIO + MODIFY_AUDIO_SETTINGS to AndroidManifest (without them the mic never works inside the APK).
- render.yaml exposes GROQ_API_KEY as well.
- Tests: 30 pass, i18n check OK (193 keys). Vite build and real-phone voice test still NOT run here (no network in this environment).
