# إزاي تشغّلي نبض على الموبايل وتبعتيه لأصحابك

عندك طريقتين، ويُفضّل تعملي الاتنين. **الأولى** هتديك رابط أي حد يفتحه على موبايله (آيفون أو أندرويد). **التانية** هتديك ملف APK لأصحابك على الأندرويد.

> **بديل مجاني لـ Gemini:** ضيفي `GROQ_API_KEY` (من console.groq.com) بدل مفتاح Gemini أو معاه. لو الاتنين موجودين وواحد خلصت حصته بيجرب التاني تلقائياً. Groq بيفهم اللهجات ويرد، والنطق بيبقى بصوت المتصفح.

> الشات الذكي والمحادثة الصوتية محتاجين الخادم (الطريقة 1). لو الخادم مش شغال التطبيق **بيفضل شغال** وبيرد من مكتبة نبض اللي جواه.

---

## الطريقة 1: رابط مباشر (أسهل وأسرع، حوالي 10 دقايق)

**1) ارفعي المشروع على GitHub**
1. اعملي حساب مجاني على github.com.
2. اضغطي **New repository** وسمّيه `nabd` (خليه Public أو Private).
3. فُكّي الضغط عن ملف المشروع، وافتحي الريبو واضغطي **Add file ← Upload files**، واسحبي كل محتويات مجلد `nabd` (من غير مجلد node_modules لو ظهر) ثم **Commit changes**.

**2) انشريه على Render (مجاني)**
1. اعملي حساب على render.com (ادخلي بحساب GitHub).
2. **New ← Blueprint** واختاري الريبو `nabd` (فيه ملف `render.yaml` جاهز)، أو **New ← Web Service** وحطي:
   - Build Command: `npm install && npm run build`
   - Start Command: `npm start`
3. من **Environment** أضيفي `GEMINI_API_KEY` (مفتاح مجاني من aistudio.google.com) عشان الشات الذكي والصوت يشتغلوا. من غيره التطبيق شغال بمكتبة نبض.
4. بعد دقايق هيطلعلك رابط زي `https://nabd-xxxx.onrender.com`. ده الرابط اللي تبعتيه.

**3) أصحابك يثبّتوه كأنه تطبيق**
- **أندرويد (Chrome):** يفتحوا الرابط ← زرار **«ثبّت التطبيق على موبايلك»** (أو قايمة ⋮ ← Install app).
- **آيفون (Safari):** زرار المشاركة ← **Add to Home Screen**.
- جوه التطبيق: **المزيد ← شارك نبض مع أصحابك** بيبعت الرابط في واتساب بضغطة.

> الخطة المجانية على Render بتنام لو محدش فتح الموقع 15 دقيقة، فأول فتحة ممكن تاخد نص دقيقة. بعدها سريع.

---

## الطريقة 2: ملف APK للأندرويد (بدون Android Studio)

ده بيتبني على سيرفرات GitHub مجاناً، بعد ما تخلصي الطريقة 1.

1. في ريبو GitHub: **Settings ← Secrets and variables ← Actions ← Variables ← New repository variable**، وأضيفي متغيرين:
   - `API_BASE` = رابط Render (مثلاً `https://nabd-xxxx.onrender.com`)
   - `PUBLIC_URL` = نفس الرابط
2. افتحي تبويب **Actions ← Build Android APK ← Run workflow**.
3. استني 5 إلى 10 دقايق، افتحي التشغيلة اللي خلصت، ونزّلي **nabd-apk** من آخر الصفحة (Artifacts).
4. فُكّي الضغط عنه هتلاقي `app-debug.apk`، ابعتيه لأصحابك على واتساب.
5. صاحبك يفتح الملف ويسمح بـ **«تثبيت من مصدر غير معروف»** مرة واحدة، فيتثبت.

ملاحظات صريحة:
- الـ APK ده للتوزيع بين الأصحاب (نسخة debug). النشر على Google Play محتاج توقيع ونسخة release وحساب مطوّر (25$ مرة واحدة).
- **الآيفون مبيقبلش ملفات APK**؛ أصحاب الآيفون يستخدموا الرابط (الطريقة 1).
- المحادثة الصوتية بتفهم أي لهجة أو لغة (التفريغ بيتم على الخادم بـ Gemini) وبترد بنفس لهجة المتكلم، وبتشتغل على كل المتصفحات اللي فيها مايك. لو Gemini وقف، بتكمل تلقائياً بتعرف المتصفح (Chrome/Edge) مع قايمة تختاري منها لهجتك.

## لو عايزة تجرّبيه على جهازك الأول
```
npm install
npm run dev:all        # الموقع على http://localhost:5173
npm test               # اختبارات المشروع
npm run check:i18n     # يتأكد أن العربي والإنجليزي مكتملين
```
